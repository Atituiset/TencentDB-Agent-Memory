TencentDB Agent Memory 深度指南

环境变量速查

按组件归类的常用环境变量。完整清单以各组件 .env.example 与配置模板为准。

MemoryCore（Gateway）

变量默认值说明
TDAI_GATEWAY_CONFIG自动发现配置文件路径
TDAI_GATEWAY_HOST127.0.0.1监听地址
TDAI_GATEWAY_PORT8420监听端口
TDAI_GATEWAY_API_KEY未设置Bearer 鉴权；非回环监听必须设置
TDAI_CORS_ORIGINS空允许的 Origin，逗号分隔
TDAI_DATA_DIR~/.memory-tencentdb/memory-tdai本地数据目录
TDAI_LLM_API_KEY空LLM API Key
TDAI_LLM_BASE_URLhttps://api.openai.com/v1OpenAI-compatible API 地址
TDAI_LLM_MODELgpt-4o模型名
TDAI_SKILL_ENABLED配置文件值强制启用 Skill 模块

配置加载优先级：TDAI_GATEWAY_CONFIG → 当前目录 → 数据目录 → 环境变量 → 内置默认。

MemoryProxy

变量说明
TDAI_MEMORY_SYSTEM_USER_IDmemory 内部服务账号 user_id
TDAI_MEMORY_SYSTEM_USER_KEY内部服务账号 apiKey
TDAI_PROXY_ADMIN_API_KEY运维端点 shared secret
PROXY_DB_PATHsqlite 后端 db 路径兜底
PROXY_FULL_STACK1 一键打开 auth + sessionInit + tdai 全流水线
PROXY_ENABLE_AUTH / PROXY_ENABLE_SESSION_INIT / PROXY_ENABLE_TDAI三大开关，可单独控制
PROXY_CONFIG_DIR指向自维护 config.yaml 目录（绕开 start-proxy.sh 覆写）

主要配置在 config.yaml（CLI 参数 > YAML > 内置默认），关键段：upstream / auth / tdai / skill / knowledge / injection / extraction / sessionInit / storage / redis / rateLimit / clickhouse / creditReport。

MemoryKnowledge

变量说明
PORT默认 8421（开发）/ 8424（合并镜像）
API_PREFIX固定 /v3
KNOWLEDGE_DATA_DIR / KNOWLEDGE_DB_PATH数据目录与 SQLite 路径
KNOWLEDGE_PUBLIC_BASE_URL写入资源 service_url；必须含 /v3 且 Agent 可达
TMC_CALLBACK_URLPanel 根地址（不带 callback path）
LLM_MODEproxy（默认，用 Panel 推送的 binding）/ custom（本地直连）
LLM_API_KEY / LLM_BASE_URL / LLM_MODEL / LLM_PROTOCOLcustom 模式的直连参数
KNOWLEDGE_AUTO_SYNC_ENABLEDAuto-Sync 总开关（默认关）
KNOWLEDGE_AUTO_SYNC_SCAN_INTERVAL_MIN扫描周期分钟数（默认 10，clamp 1–60）
KNOWLEDGE_AUTO_SYNC_MAX_CONCURRENTworker 数（默认 3，clamp 1–20）
KNOWLEDGE_CLICKHOUSE_*ClickHouse 工具调用埋点（URL/DATABASE/TABLE/USER/PASSWORD…）
LANGFUSE_PUBLIC_KEY / LANGFUSE_SECRET_KEYWiki LLM 调用 trace

Memory Hub / Panel

变量说明
REMOTE_INSTANCE_ID / REMOTE_INSTANCE_URL / REMOTE_INSTANCE_KEY单实例快捷注册（容器网内别名如 http://memory-core:8420）
REMOTE_INSTANCE_PROXY_URLUI 客户端接入地址卡片展示用
KNOWLEDGE_SERVICE_URLPanel → KS 管理地址（不带 /v3）
KNOWLEDGE_LLM_BINDING_SYNC启动时是否推送 llm_binding
METADATA_INSTANCES_CONFIG实例注册表路径

部署脚本（deploy/global-images/.env）

变量组用途
MEMORY_LLM_BASE_URL / _API_KEY / _MODELCore + Hub 内部提炼/生成用 LLM
PROXY_UPSTREAM_URL / _API_KEY / _MODELProxy 转发的上游模型
PULL=1启动前拉取最新镜像
